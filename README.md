# HR Executive Insights: Attrition & Retention Analysis

## Project Overview

This project focuses on analyzing employee attrition and workforce trends to identify patterns that may support HR decision-making.

I followed an end-to-end data analysis workflow, using SQL for data cleaning, Microsoft Excel for data analysis, and Power BI to build an interactive dashboard.

## Tools & Technologies

* **SQL:** Data cleaning and preparation
* **Microsoft Excel:** Data analysis and exploration
* **Power BI:** Data visualization and interactive dashboard
* **Data Analytics:** KPI analysis and business insights

## Project Workflow

1. Cleaned and prepared the HR dataset using SQL.
2. Imported the cleaned data into Excel for analysis.
3. Explored employee attrition, department trends, job satisfaction, salary, and other workforce metrics.
4. Imported the analyzed data into Power BI.
5. Built an interactive dashboard to present key HR metrics and insights.

## Key Dashboard Metrics

* Total Employees: 1,470
* Total Attrition: 237
* Attrition Rate: 16.12%
* Average Age: 37
* Average Salary: 6.50K

## Key Insights

* Research & Development recorded the highest attrition count, followed by Sales and Human Resources.
* Employees with an attrition status of "Yes" had a lower average monthly income than employees with an attrition status of "No".
* The dashboard provides department-wise and job-satisfaction-wise views of employee attrition.

## Dashboard

The interactive Power BI dashboard presents key workforce metrics, attrition patterns, and department-level insights.

## Project Objective

To demonstrate how SQL, Excel, and Power BI can be used together to clean, analyze, and visualize HR data for business decision-making.
